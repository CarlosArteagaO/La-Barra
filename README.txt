LA BARRA — CARTA DIGITAL
========================

La web es estática y adaptable a celular. Contiene 21 cócteles y opciones y filtros por perfil.

PUBLICAR GRATIS CON GITHUB PAGES
1. Crea un repositorio público llamado exactamente: la-barra
2. Sube index.html, styles.css y script.js a la raíz del repositorio.
3. En GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
4. Selecciona la rama main y la carpeta /(root), guarda.
5. Espera a que GitHub publique el sitio.

URL PREVISTA PARA EL QR:
https://carlosarteagao.github.io/la-barra/

El QR incluido apunta a esa URL prevista. Funcionará cuando el repositorio la-barra esté publicado en GitHub Pages bajo el usuario CarlosArteagaO.
Si publicas la web en otra dirección, hay que generar otro QR con la URL definitiva.

NOTAS
- Puedes editar recetas en script.js.
- Las cantidades son una propuesta inicial; ajusta las recetas a tu gusto.
- El QR es estático: no caduca por sí mismo, pero depende de que la URL siga activa.
